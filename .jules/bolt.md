## 2024-10-05 - Replace slow dd bs=1 with tail | head for faster file carving
**Learning:** Using `dd bs=1` for byte-level file extraction is extremely slow due to single-byte reads. The pipeline `tail -c +N | head -c M` is significantly faster and more efficient for extracting byte ranges from files, while maintaining portability.
**Action:** When carving files at byte-level granularity, prefer the `tail -c +N | head -c M` pipeline over `dd bs=1 skip=N count=M`. Ensure to properly handle indexing, as `dd skip` is 0-indexed while `tail -c` is 1-indexed (requiring `+1`). Suppress `tail` standard error to avoid SIGPIPE warnings when `head` closes the pipe. Ensure extraction checks explicitly verify both command success and that the output file size is greater than zero using `[ -s "$file" ]`.
