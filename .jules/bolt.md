## 2024-11-08 - Fast Byte-level File Carving
**Learning:** Using `dd` with `bs=1` for byte-level extraction in bash scripts causes extreme I/O and process overhead because it processes files byte-by-byte. For byte-level carving in scripts like `extract.sh` and `MCSDF_DataRescue_V21.sh`, the standard coreutils pipeline `tail -c +N | head -c M` provides significantly better performance.
**Action:** Replace `dd bs=1` with `tail -c +$((offset + 1)) "$file" 2>/dev/null | head -c $count > "$output"` for any byte-level file extraction tasks to maximize throughput while avoiding the lack of GNU-specific `dd iflag=skip_bytes` support. Always verify success with `[ -s "$file" ]` instead of `[ -f "$file" ]` because `tail|head` always produces an output file (which would be 0-bytes on failure).
